# EL3almy Gym — موقع الجيم

## هيكل المشروع
```
el3almy-gym/
├── index.html      ملف الصفحة الرئيسية
├── css/
│   └── style.css   كل التنسيقات (الألوان، الخطوط، الحركات)
├── js/
│   └── script.js   السكريبت (القائمة، الأنيميشن عند السكرول، فورم التحويل)
└── README.md
```

## طريقة التشغيل
مفيش سيرفر أو تثبيت مطلوب. افتح ملف `index.html` مباشرة في المتصفح، أو استخدم إضافة زي **Live Server** في VS Code عشان تشتغل بشكل أحسن.

## نقاط مهمة قبل النشر
- **رقم واتساب الكابتن** موجود في `js/script.js` داخل `confirmPayment()` وأيضًا في `index.html` (قسم التواصل) — الرقم الحالي: `201090044618`
- **الصور** حاليًا صور مؤقتة من Unsplash. استبدلها بصور حقيقية للجيم من داخل `index.html` (ابحث عن `<img src=`)
- **اللوجو**: الاسم مكتوب نصيًا (Typography) لحد ما يتعمل لوجو رسمي — لو جهزت لوجو، استبدل الـ`.nav-logo` و`.hero-logo` بعنصر `<img>`
- **الموقع على الخريطة**: تقريبي على منطقة كفر طحا، اضبطه لاحقًا برابط جوجل ماب الدقيق لو توفر
